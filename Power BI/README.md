# 📊 Projetos de Power BI

Coleção de dashboards e projetos desenvolvidos durante estudos e aulas de **Power BI**, com foco em análise de dados, visualização e construção de indicadores.

Os arquivos `.pbix` presentes nesta pasta representam diferentes exercícios e projetos práticos realizados ao longo do aprendizado da ferramenta.

## 🎯 Objetivo

Desenvolver e praticar conhecimentos relacionados a:

* Análise de dados;
* Criação de dashboards;
* Visualização de informações;
* Tratamento e transformação de dados;
* Criação de indicadores;
* Modelagem de dados;
* Relacionamentos entre tabelas;
* DAX;
* Power Query;
* Construção de relatórios interativos.

## 📁 Conteúdo

A pasta contém diversos arquivos `.pbix`, cada um desenvolvido durante diferentes aulas e exercícios práticos.

Os projetos exploram diferentes cenários e conjuntos de dados, permitindo praticar desde a preparação dos dados até a construção do dashboard final.

## 🛠️ Tecnologias e Recursos

* Microsoft Power BI

* Modelagem de dados
* Visualizações interativas
* Relacionamentos entre tabelas
* Indicadores e métricas
